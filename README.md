# ClinicGuard-API


ClinicGuard API is a secure patient management system for a medical clinic. It allows admins, doctors, and receptionists to manage patient records based on their roles.

Key Features
JWT user authentication
Password hashing with bcrypt
Role-based access control (Admin, Doctor, Receptionist)
Patient CRUD operations
Doctor-patient assignment
Rate limiting for security

The API ensures that only authorized users can access or modify patient information, protecting patient privacy and improving clinic management.
